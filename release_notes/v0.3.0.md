# v0.3.0

## Highlights

The card now has a **visual configuration editor**. Dropping the Adaptive
Cover Pro card onto a dashboard opens a form instead of raw YAML, with a
dropdown of known ACP instances, one checkbox per section, and a compact
mode toggle.

## Added

- **Visual card editor** (`adaptive-cover-pro-card-editor`) exposed via
  the Lovelace card picker. Contains:
  - **Instance dropdown** — lists all Adaptive Cover Pro config entries
    fetched live via `config_entries/get` websocket. Auto-selects the
    entry if there's exactly one; falls back to a raw text input if the
    fetch fails.
  - **Section toggles** — each of the six sections (Sky compass, Sun
    today, Decision strip, Cover positions, Overrides, Climate) has its
    own checkbox with a one-line description. Changes update
    `show_sections` in card YAML live.
  - **Compact mode** checkbox.
- `getConfigElement()` + `getStubConfig()` hooks on the main card — new
  cards added via the picker start with a valid stub.
- 3 new vitest cases covering `fetchAcpConfigEntries` (domain filter +
  defensive client-side filter + empty result).

## Changed

- Card now imports `adaptive-cover-pro-card-editor.ts` so the editor tag
  is registered before the picker asks for it.

## Compatibility

- Home Assistant **2024.5.0+**
- Adaptive Cover Pro integration **v2.14.0+**

## Known limitations

- Editor uses native `<select>` / `<input>` rather than `ha-select` /
  `ha-switch`. Functional but less HA-native looking; will be polished in
  v0.4 when ha-form integration lands.
- Service shortcut menu (long-press header to call
  `set_sun_tracking` etc.) still deferred — tracked in TODO.md alongside
  the integration translation_key cleanup.
