## Highlights

v2.13.0 makes the tile card read like a native Home Assistant tile instead of a generic custom one. Icons and their colors now derive from each cover's `device_class` and current state — the same logic HA's own cards use — instead of a single fixed icon. The tile also renders localized Opening/Closing/Unavailable text where it used to show nothing or a stale position, and position displays now prefer the integration's `linear_position` sensor over the plain `position` value when both are available. Badge logic and chrome layout round out the release so compact and detailed tiles match HA's own tile card more closely.

## Added

- **Cover icons and buttons derive from Home Assistant's `device_class`** (`getIconForDeviceClass()`, `CoverIconByDeviceClass`) — blinds, shades, garage doors, and other cover classes now get the icon HA would pick natively instead of one fixed icon for every cover. Refs #208, PR #211.

- **Cover icon color follows state, like stock HA cards** (`IconColorByState`) — open, closed, and moving states tint the icon the same way HA's own cover cards do. Refs #208, PR #215.

- **Tile shows localized Opening/Closing/Unavailable text** — a new `formatCoverStateText()` formatter renders the cover's motion or availability state as translated text instead of leaving the tile blank or showing a stale position. PR #210.

- **Opening/Closing shown for covers without position feedback** (`MotionType`) — covers that report motion but no live position number now show a directional state instead of appearing idle. PR #209.

## Changed

- **"Motion" renamed to "Occupancy"** across the UI and translations (`TRANSLATION_KEY_ROLES`). Refs #178, PR #205.

- **"FOV" renamed to "Sun acceptance angle" (SAA)** across the UI and translations. Refs #206, PR #207.

- **Position display now prefers `linear_position` over `position`** when the integration exposes it (`linearPositionOrFallback()`), falling back to `position` when it's absent. Refs #219, PR #221.

- **Detailed tile layout matches HA's native tile card** — spacing, icon placement, and control rows now follow the same structure as HA's stock tile. Refs #208, PR #216, PR #218.

- **Tile chrome row refined** — badges and the position bar now share the row more predictably, with the position bar shrinking to make room for badges instead of overflowing. Refs #208, PR #222.

- **"Show controls" label uses a consistent down arrow** — the expand/collapse glyph no longer varies between locales. Refs #217, PR #220.

## Fixed

- **Tile shows Unavailable when a cover goes offline** — `formatCoverStateText()` now covers the unavailable case, so an offline cover reads "Unavailable" instead of a stale or blank tile. Refs #212, PR #213.

- **Climate badge shows on the compact tile when climate is matched but not driving the cover** — the shared `matchedHandlerBadge()` helper now surfaces the badge whenever climate criteria are satisfied, not only when climate wins the pipeline. Refs #223, PR #224.

## Compatibility

- Home Assistant 2024.1+ (no change)
- Adaptive Cover Pro integration: v2.22.1+ (no new minimum imposed by this release)
- No config migration needed — existing card configs load unchanged

## Install / Upgrade

Through HACS, update to v2.13.0. A browser restart is not required.

HA caches ES modules aggressively. After updating, bump the `?v=X.Y.Z` query string on your Lovelace resource URL to ensure browsers pick up the new bundle. A hard-refresh alone is not sufficient.
