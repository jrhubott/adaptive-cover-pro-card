# v1.5.2

## Highlights

The decision strip now hides handlers that are disabled or unconfigured in the integration, reducing visual clutter when only a subset of pipeline stages are active.

## Changed

- **Decision strip hides unconfigured handlers.** Handlers not present in the integration's `decision_trace` `enabled_handlers` list are filtered out of the strip. Only handlers the integration actually evaluated are shown.

## Compatibility

- Home Assistant 2024.1+
- Adaptive Cover Pro integration 2.18.4+ (**currently in beta** — `v2.18.4-beta.3`). The handler filtering has no effect until the integration's production release ships. Install the integration beta to see this behaviour today.
