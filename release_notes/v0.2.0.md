# v0.2.0

## Highlights

Two new sections complete the dashboard: **sun elevation over today** as a
temporal complement to the spatial compass, and a **climate panel** that
surfaces ACP's summer/winter/intermediate strategy with the raw conditions
that drove it. Plus a rewrite of entity discovery to use `unique_id` via
the entity-registry websocket instead of the brittle `hass.entities`
display subset.

## Added

- **Elevation chart** (new `elevation` section, on by default) — today's
  sun elevation curve 00:00–24:00, horizon line, shaded FOV window
  (inherits ACP's configured azimuth + FOV), current-time cursor, live sun
  dot on the curve. Pure SVG, no charting library. Computed client-side
  via `suncalc` using `hass.config.latitude` / `hass.config.longitude`.
- **Climate panel** (new `climate` section, auto-hidden if climate mode is
  off) — strategy + icon (summer / winter / intermediate), active
  temperature, indoor/outdoor chips, and boolean condition chips for
  presence, sunny, lux, irradiance.
- `show_sections` default now includes `elevation` and `climate`; opt out
  with an explicit list.

## Changed

- **Entity discovery rewritten.** Card now calls `config/entity_registry/list`
  via websocket on mount (and resubscribes on `entity_registry_updated`
  events) and identifies every ACP entity by `(platform, unique_id suffix)`.
  This is the HA-canonical stable identifier — survives entity renames,
  device renames, translation changes, and integration upgrades. Replaces
  both the earlier `translation_key` path (too sparse — many ACP sensors
  don't set one) and the short-lived `entity_id` suffix regex approach
  (fragile under user renames).
- Empty state now reports registry size + ACP-matching entity count so
  discovery failures are self-explaining.
- Sky compass viewBox widened to 280 so N/E/S/W labels don't clip.

## Compatibility

- Home Assistant **2024.5.0+**
- Adaptive Cover Pro integration **v2.14.0+** (unchanged from v0.1)

## Known limitations

- No visual YAML editor yet (planned v0.3).
- Elevation chart does not yet show sunrise/sunset tick marks (inferred
  from the FOV band for now).
- No component render tests — only pure-helper unit tests.
