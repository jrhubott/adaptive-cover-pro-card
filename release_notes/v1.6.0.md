# v1.6.0

## Highlights

The Sky Compass legend now doubles as a visibility control. In multi-entry mode, clicking any cover row hides that entry's overlay — useful when several covers share the plot and their FOV wedges overlap. Click again to bring it back. Works like the hide/show behaviour in HA's `statistics-graph` card.

## Added

- **Sky Compass legend toggle.** Each cover row in the multi-entry legend is now a clickable button. Clicking hides that entry's FOV wedge, window arrow, cover-fill, and blind-spot overlays. Hidden rows appear at reduced opacity with a strikethrough so they're easy to find and re-enable. State is session-only — reloading the card resets all entries to visible.

## Compatibility

- Home Assistant 2024.1+
- Adaptive Cover Pro integration 2.18.0+
