# v1.0.0

## Highlights

First stable release. The card delivers on the plan end-to-end: one
`entry_id` in YAML, six live-updating sections, a visual editor, a
compact mode that actually compacts, and discovery that rides HA's
canonical identity model (entity-registry websocket + `unique_id`
matching). From here out, any `1.x.y` release will preserve the current
YAML config shape — breaking changes wait for `v2.0.0`.

## What the card does, at a glance

- **Header strip** — instance name · cover-type icon · `Integration
  Enabled` / `Automatic Control` toggles in-place
- **Sky compass** — SVG polar plot of window FOV + blind-spot wedge,
  sun dot tracked in real time, cardinal labels, gamma/elevation stats
- **Sun today** — 24-hour elevation-vs-time curve with the sun-in-FOV
  window shaded, horizon line, live now-cursor and sun dot
- **Decision strip** — all 10 pipeline handlers in priority order,
  matched/skipped state, the winning handler highlighted with its
  proposed position
- **Cover positions** — per-cover live vs. target bars with mismatch
  indicator; click the track to set a position
- **Overrides panel** — manual-override countdown, force-override
  sensor count, motion-timeout status, one-click reset
- **Climate panel** — auto-hidden unless the instance has climate mode
  configured; shows strategy (summer / winter / intermediate), active
  temperature, indoor/outdoor chips, and boolean condition chips

## Installation

**HACS (recommended):** Add `https://github.com/jrhubott/adaptive-cover-pro-card`
as a custom repository (category: **Lovelace**). The card will appear in
the picker.

**Manual:**

```bash
mkdir -p www/community/adaptive-cover-pro-card
wget -O www/community/adaptive-cover-pro-card/adaptive-cover-pro-card.js \
  https://github.com/jrhubott/adaptive-cover-pro-card/releases/latest/download/adaptive-cover-pro-card.js
```

Then add a dashboard resource:

```yaml
url: /local/community/adaptive-cover-pro-card/adaptive-cover-pro-card.js?v=1.0.0
type: module
```

The `?v=1.0.0` cache-buster tells the browser to refetch when you later
update the bundle. Bump it on every card upgrade.

## Usage

```yaml
type: custom:adaptive-cover-pro-card
entry_id: YOUR_CONFIG_ENTRY_ID
# Optional:
show_sections: [sky, elevation, decision, covers, overrides, climate]
compact: false
```

Or just drop the card onto a dashboard — the visual editor handles all
of the above.

## Known limitations (deferred to TODO.md)

- **No GitHub Wiki pages yet** — content is staged in `TODO.md`; Wiki
  needs a one-click initialisation in the web UI before the sibling
  `.wiki` repo is reachable.
- **Visual editor uses native `<select>` / `<input>`** — functional but
  not design-system native. `ha-select` / `ha-switch` polish planned for
  v1.1.
- **No service shortcut menu** — long-press-header sheet for ACP
  runtime services (`set_sun_tracking`, `set_climate`, etc.) is still
  deferred.
- **Sky-compass radial axis is unlabelled.** The three rings are at
  0° / 30° / 60° elevation but carry no tick labels today.
