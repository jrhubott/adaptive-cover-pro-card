# v2.0.0-beta.5

## Highlights

This beta lands two things that were open in beta.4: the French translation is no longer draft — @environ314 has reviewed it and corrections are applied, so the FR table in `src/lib/i18n/fr.ts` now reflects native-speaker input rather than machine output. Alongside that, open/close position writes on both the tile card and the main card's cover bars now route through `adaptive_cover_pro.set_position` instead of the generic `cover` domain services, which lets the integration absorb the command without fighting its own adaptive control loop. If you run the card in French or have covers that race between manual and automatic control, this is the beta to test.

## Changed

- **Position writes route through `adaptive_cover_pro.set_position`** — the tile card's open and close buttons (formerly `cover.open_cover` / `cover.close_cover`) now call `adaptive_cover_pro.set_position` with `position: 100` and `position: 0` respectively via `_setCoverPosition` in `src/adaptive-cover-pro-tile-card.ts`. The cover bar's drag-to-set path in `src/components/cover-bar.ts` changed the same way, replacing `cover.set_cover_position`. Stop remains on `cover.stop_cover` — the integration has no equivalent stop service. This prevents the integration's adaptive loop from immediately overriding a manual position write with a competing `cover` service call. (#67, #70)
- **French translation updated with native-speaker corrections** — `src/lib/i18n/fr.ts` previously held best-effort machine translations drafted for review. @environ314's corrections are now applied: the file reflects reviewed, idiomatic French across all keys. (#64, #72)

## Fixed

- **`scripts/release --dry-run` ignored unless it was the first argument** — the flag is now scanned from all positional arguments, so `scripts/release beta --dry-run` no longer silently performs a real release.

## Beta testing

- Bump the Lovelace resource URL to `?v=2.0.0-beta.5` in Settings → Dashboards → Resources — HA caches ES modules aggressively and a hard-refresh alone will not pick up the new bundle.
- **French**: set HA's language to `fr`, reload the card, and check that UI strings read naturally. Corrections still welcome in #64.
- **Position routing**: trigger an open or close from the tile card controls and from the cover bar, then confirm in the HA logbook that the service call logged is `adaptive_cover_pro.set_position` rather than `cover.open_cover` / `cover.set_cover_position`. Verify that stop still works (it stays on `cover.stop_cover`).

## Compatibility

- Home Assistant 2024.1+
- **Adaptive Cover Pro integration `v2.22.1-beta.3` or newer required** — this beta depends on integration-side entity and attribute additions, including the `adaptive_cover_pro.set_position` service. Earlier integration versions will cause the tile card and dialog to degrade or show empty state.
