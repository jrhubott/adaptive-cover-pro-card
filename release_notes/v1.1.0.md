# v1.1.0

## Highlights

This release deepens the sky compass visualization and gives installers finer
control over which controls are user-editable. The sky compass now draws the
full daily solar arc — a dashed path showing where the sun travels from sunrise
to sunset — with labeled markers at both endpoints, making it easy to see at a
glance whether a window's field of view captures any useful light. Per-control
read-only flags let you lock specific switches (integration enabled, automatic
control, override reset) so they cannot be accidentally toggled from the card UI.

## Added

- **Sun path arc** — dashed daily solar trajectory drawn on the sky compass,
  from sunrise to sunset azimuth, at the current date's declination.
- **Sunrise/sunset dot markers** on the sky compass with azimuth labels.
- **Sky compass legend** updated to document all visual elements (sun dot, FOV
  wedge, sun path arc, markers).
- **Compass stats toggle** — new config option to show/hide the azimuth/elevation
  readout beneath the compass.
- **Per-control read-only flags** — `disable_integration_enabled`,
  `disable_automatic_control`, and `disable_reset_manual_override` config options
  lock the corresponding controls to display-only. Useful when the integration is
  managed by automations and you don't want the card to override them.
- **`hide_inactive_handlers` option** on the decision strip — collapses handler
  rows that did not participate in the last decision cycle, reducing visual noise
  when only a few handlers are active.
- **Header pill** component — compact section header shown in compact mode.
- **Local deploy scripts** (`scripts/deploy`, `scripts/deploy-local`) for
  pushing a development build directly to a local HA instance.

## Changed

- Section headers are hidden in compact mode (header pill takes over).
- Below-horizon sun dot now renders in a distinct color (was previously
  indistinguishable from an above-horizon dot at dusk/dawn).
- Sky compass visual editor wired up for all new options.

## Fixed

- Below-horizon sun dot color was incorrect.

## Compatibility

- Home Assistant 2024.1+
- Adaptive Cover Pro integration 1.1.0+
