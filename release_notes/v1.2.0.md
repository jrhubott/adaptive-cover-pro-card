# v1.2.0

## Highlights

Entity discovery is now significantly faster on subsequent loads. The card caches the HA entity registry in `localStorage` and subscribes to filtered registry updates, so the full registry fetch only happens once per browser session (or when entities actually change). This eliminates the brief delay on every Lovelace reload where the card was waiting on a full `config/entity_registry/list` websocket response.

## Added

- **localStorage registry cache** — entity registry is persisted across page loads (`src/lib/registry-cache.ts`). Cache is invalidated automatically when `entity_registry_updated` events arrive.
- **Memoized entity discovery** — `discoverEntities()` skips re-computation when the registry snapshot is unchanged.
- **Filtered registry subscription** — subscribes to `entity_registry_updated` events filtered to the current config entry, reducing unnecessary re-renders.

## Fixed

- Deploy script now uses `/usr/bin/python3` explicitly for the HA websocket call, fixing failures on systems where `python3` is not on `$PATH`.

## Compatibility

- Home Assistant 2024.1+
- Adaptive Cover Pro integration v1.1.0+
