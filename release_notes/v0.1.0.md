# v0.1.0

## Highlights

First release of the Adaptive Cover Pro companion Lovelace card. One glance shows *what* the integration is doing, *why* it decided that, and *how* to take over — all from a single `entry_id` in YAML.

## Added

- **Sky compass** — SVG polar plot of window FOV, blind spot, and live sun position. Elevation maps to radius so low winter suns sit near the edge.
- **Decision strip** — all 10 pipeline handlers in priority order with matched/skipped state, winning handler highlighted, full reason text.
- **Cover positions** — per-cover live vs. target bars with mismatch warnings; click the track to set a position.
- **Overrides panel** — manual override countdown, force-override sensor count, motion timeout status, one-click reset button.
- **Entity discovery** — single `entry_id` in YAML auto-discovers all ~20 integration entities by `translation_key`. No per-entity boilerplate.
- **HACS distribution** — `hacs.json` declares the card as a plugin, `publish-release.yml` attaches the built bundle to each release.

## Compatibility

- Home Assistant **2024.5.0+**
- Adaptive Cover Pro integration **v2.14.0+** (custom position handler + current `translation_key` scheme)

## Known limitations

- No visual YAML editor yet — card must be configured via raw YAML / ManualCardElement.
- Climate panel and elevation-vs-time chart are planned for v0.2.
- Tilt covers render in the cover bar but tilt angle is not yet visualized.
