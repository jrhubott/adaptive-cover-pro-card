# v0.4.0

## Highlights

Phase 4 polish pass. Compact mode now actually compacts (each section
tightens its own layout), the card has component-level smoke tests, and
initial renders are guarded so the card never throws before HA has
finished binding props.

## Added

- **Compact mode propagates to every section.** Each component gains a
  `compact` boolean property that's reflected as a host attribute, and
  CSS uses `:host([compact])` selectors to tighten its own density:
  - Sky compass shrinks to 180 px max width and hides the legend.
  - Sun-today chart aspect ratio tightens from 400:160 to 400:110.
  - Decision strip drops font to 0.72 rem, tightens columns, hides the
    bottom reason line.
  - Cover bar halves track height and shrinks font.
  - Overrides panel reduces tile padding and hides the countdown
    sub-text.
  - Climate panel shrinks the strategy line and tightens temp cards.
- **Component render tests.** 7 new vitest cases exercising the decision
  strip (10 rows + winner highlight, placeholder when trace is absent),
  cover bar (one row per managed cover, placeholder when empty),
  overrides panel (reset-button conditional rendering), and compact
  attribute reflection.
- **Initial-render guards.** Each section component returns `nothing`
  when `hass` or `discovered` is still undefined. Matches the existing
  pattern on the card root; prevents crashes during the tiny window
  between element creation and prop assignment.

## Changed

- `theme` config field removed. It was declared but never implemented —
  Home Assistant's own theme system already flows through every CSS
  variable the card uses, so the field was dead weight.
