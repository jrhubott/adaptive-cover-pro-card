# v2.0.1

## Highlights

v2.0.1 is a polish patch on top of v2.0.0. The sky compass now renders the active window arc correctly for any window orientation — previously it always swept clockwise from sunrise to sunset, tracing the wrong half of the sky for north-facing windows. The decision strip surfaces `floor_clamp` as an explicit 11th pipeline handler instead of applying silently. And the compact tile card gains a floor chip that shows which min-mode slot is currently constraining the cover position — faded when armed but not clamping, full color when it's the active floor.

## Fixed

- **Sky compass active arc** — the field-of-view wedge now picks the arc that contains the window normal rather than always sweeping clockwise from sunrise azimuth to sunset azimuth (#85). For north-facing windows the clockwise sweep traced the wrong half of the sky; the corrected logic computes both possible sweeps and selects the one that contains the window direction.

- **Decision strip shows the `floor_clamp` post-processing step** — `floor_clamp` was applying to the final position silently, invisible in the pipeline UI (#87). It is now listed as the 11th handler in `HANDLER_ORDER` and labeled "Min Floor" (English) / "Plancher" (French), so you can see at a glance when a min-mode floor is constraining the computed position.

## Added

- **Tile card min-mode floor chip** — when a min-mode custom-position slot is armed, the tile card renders a floor chip showing the slot's position (#86). The chip is faded when the floor is armed but a higher-priority result is already above it, and full color (purple) when the floor is actively clamping the cover. Helps you identify which slot is the operative floor without opening the more-info dialog.

## Compatibility

- Home Assistant 2024.1+
- Adaptive Cover Pro integration `v2.22.1-beta.3` or newer
