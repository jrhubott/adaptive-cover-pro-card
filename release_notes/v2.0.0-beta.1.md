# v2.0.0-beta.1

## Highlights

The 2.0 line adds a dense tile card designed for dashboards with many Adaptive Cover Pro covers. A single compact row shows the cover icon, instance name, live position, quick ↑■↓ controls, and a contextual badge summarising what the integration is doing — `Auto`, `Manual · 04:35 PM`, `Custom · Table extension · 60% floor`, and so on. Tapping the tile opens an ACP-specific dialog with the plain-English "why this position?" sentence, a today's-forecast strip, enable toggles for Automatic/Climate/Motion, and a collapsible Advanced section that surfaces the full Sky Compass, decision strip, overrides panel, and climate panel. A visual editor lets you configure the tile without touching YAML. **This beta requires Adaptive Cover Pro integration `v2.22.1-beta.3` or newer** — it depends on integration-side entity additions introduced alongside this card work.

## Added

- **`adaptive-cover-pro-tile-card`** — new custom element (`src/adaptive-cover-pro-tile-card.ts`) optimised for dense dashboards. Shows cover icon, entry title, current position, ↑■↓ control buttons, contextual badge, and an inline Resume button that appears when a manual or custom-position override is constraining the cover.
- **`acp-tile-badge`** (`src/components/tile-badge.ts`) — pill-shaped status badge whose kind (`auto`, `manual`, `custom_position`, `sun`, `motion`, `force`, `cloud`, `off`) is derived from the integration's pipeline winner. Manual badges show the override end time as a clock; custom-position badges show slot name or number plus percent and a `floor` suffix when minimum-mode is active.
- **`acp-more-info-dialog`** (`src/components/more-info-dialog.ts`) — card-rendered dialog (not HA's built-in more-info) opened on tile tap. Header carries cover icon, entry title, all simultaneously matched handler badges priority-ordered, and a close button. Body has the plain-English decision sentence, target position with mismatch indicator, per-cover bars, today's forecast strip, Automatic/Climate/Motion toggle chips, a Resume Auto button, and a collapsible Advanced section embedding `acp-sky-compass`, `acp-decision-strip`, `acp-overrides-panel`, and `acp-climate-panel`.
- **`acp-forecast-strip`** (`src/components/forecast-strip.ts`) — hand-written SVG strip rendering the integration's `position_forecast` sensor data as a position curve with colour-coded boundary event markers (`sunrise`, `sunset`, `fov_enter`, `fov_exit`). No charting library; scales to fit its container.
- **`adaptive-cover-pro-tile-card-editor`** (`src/adaptive-cover-pro-tile-card-editor.ts`) — `ha-form`-driven visual editor for the tile card. Exposes `icon`, `show_controls`, `show_badge`, `show_resume` (`auto`/`always`/`never`), `show_decision_summary`, `tap_action`, `hold_action`, and `double_tap_action`. The entry picker reuses `discoverEntities` for live filtering.
- **`buildDecisionSentence`** (`src/lib/decision-summary.ts`) — helper that walks matched handlers in reverse priority order and produces a human-readable pipeline sentence ending at the winner. Custom-position rows render the sensor's friendly name when available, fall back to `#N`, and append `floor` only when minimum-mode is actively constraining. Used by both the dialog and the decision strip.
- **`pickCoverIcon`** (`src/lib/icons.ts`) — selects open/partial/closed MDI icon variants based on live cover position, using a 5/95 deadband to prevent flicker near the rails.
- **Position-aware tile icon** — the tile card swaps between cover-type-specific open, partial, and closed icon variants as position changes.
- **Sky Compass in the more-info dialog** — the existing `acp-sky-compass` component is embedded in the dialog's Advanced section in compact mode.
- **Decision summary line in the decision strip** — `acp-decision-strip` now renders the plain-English sentence above its handler row grid, gated by `show_decision_summary` (defaults `true`).

## Changed

- **`acp-decision-strip`** — `normalizeHandler` extracted to `src/lib/decision-summary` and re-imported, so the strip and the decision-sentence helper share one normalisation path. Multi-slot installs now aggregate correctly because per-slot `custom_position_<N>` handler names collapse to `custom_position`.
- **`acp-tile-badge` integration state** — badge reflects `integration_enabled` and `automatic_control` switch states; when the integration is off the badge renders an `Off` pill regardless of winner.

## Fixed

- **Tile editor defaults** — the `ha-form` editor now pre-fills with runtime defaults so toggles reflect actual behaviour on first open; keys matching defaults are stripped on emit to keep YAML minimal.
- **Tile overflow / badge clipping** — card overflow is clipped and the badge is allowed to shrink so the Resume pill no longer escapes the right edge on narrow widths.
- **Two-line tile layout** — opt-in `layout: one-line | two-line` config; two-line mode stacks title/position on row 1 and controls/badge/resume on row 2.
- **Forecast strip "now" cursor** — removed the redundant vertical cursor that always sat at the left edge (`x=0`) instead of the current time.
- **More-info dialog Resume gating** — Resume Auto is hidden unless manual override is on or the winner is a custom-position slot, matching the tile's inline rule.

## Beta testing

Install via HACS using the "show beta versions" toggle. After installing, bump the resource URL cache-buster in Settings → Dashboards → Resources to `?v=2.0.0-beta.1` — HA aggressively caches Lovelace module URLs and a hard-refresh alone will not pick up the new bundle. Focus feedback on: tile rendering at different dashboard widths, badge accuracy across all handler kinds, the more-info dialog on mobile, and forecast strip behaviour when the integration's `position_forecast` sensor is absent or has no samples.

## Compatibility

- Home Assistant 2024.1+
- **Adaptive Cover Pro integration `v2.22.1-beta.3` or newer required** — this beta depends on integration-side entity and attribute additions. Earlier integration versions will cause the tile card and dialog to degrade or show empty state.
