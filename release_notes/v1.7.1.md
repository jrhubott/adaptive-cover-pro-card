# v1.7.1

## Highlights

Two Sky Compass fixes. Awnings now fill the FOV wedge in the right direction (previously inverted — closed awnings looked open and vice versa), and the legend swatches finally match the colors they describe, using the same theme tokens as the graph.

## Fixed

- **Awning cover-fill polarity (#50).** The wedge fill direction was inverted for `cover_type: awning`. Awnings now use `position/100` for the fill fraction (extended = filled) while blinds and tilt-only covers keep `1 - position/100` (closed = filled). Tooltip text branches to match: "Cover extended" for awnings, "Cover closed" for blinds.
- **Sky Compass legend colors (#48).** Legend swatches and labels now use the same theme tokens as the corresponding graph elements (sun path, FOV wedge, cover fill, window arrow, blind-spot bands), so visual identification matches the plot in both light and dark modes.

## Changed

- `npm run lint` now includes the Prettier format check, so local lint matches CI behaviour. Previously format drift could slip past `npm run lint` and only fail in CI.

## Compatibility

- Home Assistant 2024.1+
- Adaptive Cover Pro integration 1.7.0+
