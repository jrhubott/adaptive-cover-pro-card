# v1.5.1

## Highlights

The blind spot wedge on the Sky Compass was drawn in the wrong position because the integration sends the range as FOV-relative offsets, not absolute bearings. This patch converts those offsets to absolute compass bearings before rendering, so the wedge now appears where the blind spot actually is.

## Fixed

- **Blind spot wedge mis-positioned on Sky Compass.** The integration's `blind_spot_range` values are offsets relative to the window's field-of-view, not absolute azimuths. The card was passing them to `wedgePath` as absolute bearings, placing the wedge in the wrong direction. A new `blindSpotBearings()` helper converts them to absolute compass bearings before rendering. The tooltip readout is also corrected to show the true bearings.

## Compatibility

- Home Assistant 2024.1+
- Adaptive Cover Pro integration 1.4.0+
